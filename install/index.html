Install help

Install Kaveret, step by step

Kaveret is new and free, so it isn't signed with a paid certificate yet. That is why Windows, macOS and Android ask once before the first start. Below is exactly what to click. It does not mean anything was found in the file.

Windows Mac Android What your computer needs Check the file

Windows

Download Kaveret-Setup.exe
  1. Open Kaveret-Setup.exe from your downloads. If the browser says the file isn't commonly downloaded, choose Keep.
  2. Windows shows a blue window: "Windows protected your PC". Click More info (the small link under the text), then Run anyway.
  3. Finish the setup. Kaveret opens with Buddy, ready to connect your first subscription.

Mac Beta

Which Mac do you have? Apple menu › About This Mac. "Chip: Apple M1, M2, M3…" means Apple chip. "Processor: … Intel …" means Intel.

Mac with Apple chipMac with Intel
  1. Open the .dmg file and drag Kaveret into Applications.
  2. The first time, in Applications, right-click (or Control-click) Kaveret and choose Open, then Open again.
  3. On macOS 15 or newer: open it once and click Done. Then go to System Settings › Privacy & Security, scroll down and click Open Anyway.

If macOS says Kaveret "is damaged"

This is macOS being careful with an app from the internet, not a broken file. Try the steps above first. Only if it still won't open: open the Terminal app, paste this line, press Enter, and open Kaveret again.

xattr -cr /Applications/Kaveret.app

On Mac, updates aren't automatic yet: to update, download the new file and install it over the old one.

Android Test build

The Android app is a remote control for Kaveret on your computer. The computer has to be on, with Kaveret open. Set up phone access on the computer first: the phone setup guide shows how.

Download Kaveret.apk
  1. On the phone, download Kaveret.apk and open it.
  2. Android asks whether to allow installs from this source (your browser or Files). Tap Settings, turn on Allow from this source, go back and tap Install.
  3. If Google Play Protect warns that it doesn't know the app, tap More details, then Install anyway. It warns because the app isn't on Google Play yet.
  4. On first start, enter the address that Kaveret on your computer shows in Settings › Devices.

iPhone: there's nothing to install. The phone setup guide shows how to add Kaveret to your home screen.

What your computer needs

  • Windows: Windows 10 or 11, 64-bit.
  • Mac: macOS 12 (Monterey) or newer, with an Apple chip or Intel.
  • Memory: 8 GB of RAM recommended.
  • Disk: the download is about 135 MB on Windows and about 140 MB on Mac. Keep at least 2 GB free for the app, its data and the AI tools it installs.
  • Android phone: Android 7 or newer. The app is about 5 MB.
  • Internet: needed while you work, because the AI runs at each company you connect.
  • Linux: no installer yet; Kaveret runs from its source code. The full install guide has the steps.

Check the file (optional)

Every release lists a SHA-256 code for each file in SHA256SUMS. To be sure your file is the one the project published, compare its code with that list.

  • Windows: in PowerShell, in your Downloads folder: Get-FileHash .\Kaveret-Setup.exe
  • Mac: in Terminal, in your Downloads folder: shasum -a 256 Kaveret-mac-arm64.dmg (or Kaveret-mac-x64.dmg)
